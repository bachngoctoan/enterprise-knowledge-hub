An enterprise-grade, multi-tenant AI knowledge management platform built with .NET 10, PostgreSQL, pgvector, and Large Language Models (LLMs).

The platform enables organizations to ingest, process, index, and retrieve knowledge from documents using Retrieval-Augmented Generation (RAG). It features semantic search, hybrid retrieval, contextual conversations, source citations, document-level access control, and AI-powered question answering.

Designed with Clean Architecture and production-ready engineering principles, including tenant isolation, observability, evaluation pipelines, security, and scalable AI integration.
